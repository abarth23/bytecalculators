## 🛠️ Calculators Suite

### 🤖 1. AI Infrastructure & LLM Economics
* **[ChatGPT & LLM API Cost Calculator](https://bytecalculators.com/chatgpt-api-cost-calculator)** — Forecast prompt and completion token costs across OpenAI, Claude, and Gemini.
* **[DeepSeek vs. OpenAI Cost Comparator](https://bytecalculators.com/deepseek-vs-openai-cost-calculator)** — Compare inference pricing for DeepSeek V3/R1 against GPT-4o.
* **[LLM VRAM Calculator](https://bytecalculators.com/llm-vram-calculator)** — Estimate required GPU VRAM across quantizations (FP16, INT8, INT4).
* **[AI Agent ROI & Recursive Loop Simulator](https://bytecalculators.com/ai-agent-roi-calculator)** — Model cumulative context growth in autonomous agent loops vs. human VA rates.
* **[AI Video Studio Planner](https://bytecalculators.com/ai-video-cost-calculator)** — Production budget and credit forecasting for Runway Gen-3, Kling, and Luma.
* **[Prompt Caching Optimizer](https://bytecalculators.com/prompt-caching-optimizer)** — Quantify cost savings using Claude and OpenAI prompt cache breakpoints.

### 💼 2. Startup Economics & SaaS Metrics

* **[LTV vs. CAC Unit Economics Calculator](https://bytecalculators.com/ltv-vs-cac-calculator)** — Measure customer acquisition payback periods and churn health.
* **[Quit Your Job Side-Hustle Viability Index](https://bytecalculators.com/quit-your-job-calculator)** — Financial safety model for transitioning from employee to full-time founder.

### 🎥 3. Creator Economy & Web3

## 🚀 Tech Stack

Built with modern web technologies focused on extreme speed, zero layout shift, and instant client-side computation:

* **Framework:** [Astro](https://astro.build/)
* **Runtime:** Client-side Web APIs & Encapsulated Shadow DOM
* **Styling:** Custom CSS Custom Properties (Dark Cyberpunk / Linear-inspired UI)

## 💻 Local Development

Clone the repository and install dependencies:

```bash
git clone https://github.com/YOUR_USERNAME/bytecalculators.git
cd bytecalculators
npm install
npm run dev
```

Visit `http://localhost:4321` in your browser.
